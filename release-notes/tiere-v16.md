# AnimalFarmingToDoList v16 🐾

Die To-do-App, in der aus jedem Haken ein Stück Tierfamilie wird.

**Installieren:** <https://peguindevelopment.github.io/AnimalFarmingToDoList/>
Auf dem iPhone in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Auf Android in Chrome öffnen → ⋮ → „App installieren“.
Wer schon installiert hat, bekommt das Update beim nächsten Öffnen mit Internet automatisch. Alle Daten bleiben erhalten.

## Verbessert

- **Antippen geht sofort:** Die Babytiere auf der Tierwiese hüpfen jetzt direkt beim ersten Antippen. Vorher reagierten sie manchmal erst Sekunden später. Außerdem trifft man das Tier jetzt auch, wenn man zwischen Ohren oder Beine tippt.
- **Passt auf jeden Bildschirm:** Die Schrift richtet sich nach der Bildschirmbreite, und nichts wird mehr über den Rand geschoben. Das betrifft vor allem die Farbthemen, den Namenswürfel beim Schlüpfen und die Kacheln im Laden, besonders auf iPhones und bei großer Systemschrift.

## Download

`AnimalFarmingToDoList-v16.zip` enthält die komplette App zum Archivieren oder selbst Hosten. Zum normalen Benutzen reicht der Link oben.
